# Muestras reales de la API

Esta carpeta se llena al ejecutar `npm run audit` con tu token.
Aún no hay muestras: no se inventan datos. Hasta ejecutarlo, los tipos del Paso 2 no pueden definirse.
Se generan `*.json` (3 primeros elementos de cada endpoint) y `_report.json` (estado, cabeceras, campos, campos de imagen).

## Fuentes complementarias (Paso 12.3.1)
`npm run audit:sources` guarda muestras en `docs/samples/citoapi/`, `docs/samples/leaguepedia/` y `docs/samples/oracleselixir/` (solo cabecera y 3 filas) y el informe `_report_sources.json`. Tampoco se inventan datos aquí: las carpetas aparecen al ejecutarlo.
